El objetivo de este proyecto es construir una máquina de decisión simple (conocida en inteligencia artificial como un perceptrón manual) capaz de clasificar imágenes binarias de 3 X 3 píxeles. Específicamente, el sistema debe decidir de forma automática si una imagen representa la letra 'T' o 'No es una T'. La principal restricción del problema es que no podemos usar ninguna librería de Machine Learning (como Tensor Flow o Scikit-Learn). Toda la lógica matemática de reconocimiento debe ser programada de forma pura en Python. Para resolver esto sin algoritmos complejos, el código simula una neurona artificial básica que funciona en tres pasos secuenciales: Entrada de Datos: Cada imagen de prueba es una lista de 9 números, donde un 1 representa un píxel activo (dibujado) y un 0 un píxel vacío. Cálculo del Puntaje (Score): Cada uno de los 9 píxeles tiene asignado un 'peso' matemático (W1 a W9). El programa multiplica cada píxel de la imagen por su respectivo peso y suma todos los resultados: Score = (Píxel1 x W1) + (Píxel2 x W2) + …….. + (Píxel9 + W9) Regla de Clasificación: Finalmente, el Score obtenido se compara contra un umbral o Threshold. Si el puntaje supera este umbral, la máquina predice que 'Es una T'; de lo contrario, determina que 'No es una T'. Para cumplir con el requisito de interactividad, utilizamos la librería Tkinter para desplegar una interfaz visual. Esta interfaz le permite al usuario: Seleccionar diferentes ejemplos (positivos y negativos). Modificar el Threshold en tiempo real. Ajustar de forma manual los 9 sliders de los pesos para 'entrenar' a la máquina. Nuestra estrategia ganadora: En la demostración práctica, descubrimos una configuración matemática muy robusta basada en la penalización del fondo. Dejamos los pesos del centro y arriba en 0.0 (donde se dibuja la T), pero configuramos las esquinas en su valor mínimo (-2.0). De esta forma, si una imagen intrusa intenta activar las esquinas, los pesos negativos tumban el puntaje de inmediato a cero o números negativos, permitiendo que el Threshold (fijado en 2.0) separe perfectamente las 'T' reales de cualquier otra línea o figura intrusa sin cometer errores.
